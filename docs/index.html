NEPSE Scraper Documentation

API Endpoints

Get Stock Data by Symbol

Route: /:symbol

Method: GET

Description: Retrieves the latest stock data for a specific symbol.

Parameters:

  • symbol (URL Parameter, required): The stock symbol (e.g., 'NABIL'). Case-insensitive, will be redirected to uppercase.

Example:

GET /NABIL

Get List of Top Stocks

Route: /

Method: GET

Description: Retrieves a list of top stocks based on specified criteria.

Parameters:

  • col (Query Parameter, optional): The column to sort by (e.g., 'change', 'volume').
  • num (Query Parameter, optional): The number of results to return (default: 10).

Example:

GET /?col=change&num=5
